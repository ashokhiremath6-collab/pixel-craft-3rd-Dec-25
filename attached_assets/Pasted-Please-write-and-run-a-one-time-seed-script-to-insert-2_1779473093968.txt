## Things to be careful about

- **Body field formatting.** The bodies contain markdown-style formatting (`**bold**`, lists, line breaks). These must be preserved exactly. The body is meant to be displayed as-is, so any markdown rendering happens at the display layer, not at insert time.

- **Quotes in body content.** Some SOPs contain quoted text. Use proper SQL escaping (parameterized queries) — do NOT use string concatenation that could break on apostrophes or quotes.

- **Don't truncate.** Some bodies are 1500-2000 words long. If your insert script has a length limit, increase it. The `content` field is likely `text` type in Postgres which has no length limit, but verify.

- **If the table has more required fields than I've listed**, ask me before guessing. Don't make up data for fields like `tags`, `version`, or `priority`.

Do not modify any other table, do not change schema, do not modify any application code.
