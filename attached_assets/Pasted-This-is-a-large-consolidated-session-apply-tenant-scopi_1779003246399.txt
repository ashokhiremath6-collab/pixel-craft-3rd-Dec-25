PATTERNS
==============================================================

GROUP A — Per-tenant pattern

  Read (list):
    db.select().from(T).where(eq(T.orgId, orgId))

  Read (by id):
    db.select().from(T)
      .where(and(eq(T.id, id), eq(T.orgId, orgId)))
      .limit(1)

  Read (by other field, e.g. by parent FK):
    db.select().from(T)
      .where(and(eq(T.parentId, parentId), eq(T.orgId, orgId)))

  Insert:
    db.insert(T).values({ ...input, orgId }).returning()
    // The spread-then-overwrite ensures route input can never override orgId

  Update:
    const { orgId: _ignored, ...safeUpdates } = updates;
    db.update(T).set(safeUpdates)
      .where(and(eq(T.id, id), eq(T.orgId, orgId)))
      .returning()
    // Prevents tenant from reassigning rows to another tenant

  Delete:
    db.delete(T).where(and(eq(T.id, id), eq(T.orgId, orgId))).returning()

  Cascade deletes inside transactions (e.g. deleteProjectVendor cascades to quoteFiles/boq/etc):
    Every cascade child delete must also include eq(child.orgId, orgId).
    Even though the parent FK relationship would naturally scope, defence-in-depth says filter both.

GROUP B — Global-with-tenant-override pattern

  Read (list — returns global + tenant-owned):
    db.select().from(T).where(or(isNull(T.orgId), eq(T.orgId, orgId)))

  Read (by id — returns the row only if it's global OR belongs to the tenant):
    db.select().from(T)
      .where(and(eq(T.id, id), or(isNull(T.orgId), eq(T.orgId, orgId))))
      .limit(1)

  Insert (always tenant-owned — tenants cannot create global rows from the API):
    db.insert(T).values({ ...input, orgId }).returning()

  Update (only the tenant's own rows; globals are immutable from the API):
    const { orgId: _ignored, ...safeUpdates } = updates;
    db.update(T).set(safeUpdates)
      .where(and(eq(T.id, id), eq(T.orgId, orgId)))   // NOT NULL — never global
      .returning()
    // If the row is global (org_id IS NULL), this returns no rows. Caller should treat that as "not found or not yours".

  Delete (same restriction — globals untouchable):
    db.delete(T).where(and(eq(T.id, id), eq(T.orgId, orgId))).returning()
